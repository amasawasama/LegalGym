按步骤准备，再开始一次新运行

当前版本需要在你的电脑上启动任务环境和 Agent。公开网页暂不提供云端运行。

  1. 1

    准备本机环境

    下载并解压启动包。Mac 运行 Start-Mac.command，Windows 运行 Start-Windows.cmd；脚本自动准备 Python、浏览器和项目依赖。

    下载自动配置启动包
  2. 2

    配置模型，等待连接

    在启动窗口填写自己的模型接口、模型名和 API Key。配置完成后会自动打开本机运行页，请保持启动窗口打开；密钥不保存到文件。

  3. 3

    在本机运行页开始任务

    选择已连接的示例 Agent，点击“开始运行”。日志、运行记录和 Word 交付都在该页查看；模型调用可能产生费用。

安装说明与手动启动方式

启动包为预览版，尚未完成全新 Mac / Windows 实机安装验证。新任务可下载 Word，页面预览需要另配文档渲染器。

也可以下载完整项目源码，按 README 安装并启动环境。手动启动的默认本机地址为 http://127.0.0.1:8841/lab/；自动启动器使用的地址以它实际打开的页面为准。

Agent 来源：你的程序

用 Starter 对接任务和工具

你自行选择模型、框架和策略。当前连接目标仍是本机 LegalGym 环境，公网环境接口尚未开放。

  1. 1

    获取接入范例

    Starter 内含接入 README、可运行的 demo_agent.py 和 adapter_template.py。下载 Starter 本身不会安装或提供任务环境。

    下载 Agent Starter
  2. 2

    适配你的 Agent，并准备环境

    实现 run(task, environment, report)：把本次任务与工具定义交给自己的 Agent，真实工具调用经由 environment.call_tool 执行，并回传结果。交付须通过 submit 提交。

    还没有本机任务环境？

    可以先按示例 Agent 的步骤准备环境；自动启动器会先连接示例 Agent。之后另行启动自己的 Starter，并在在线列表中选择自己的 Agent。

  3. 3

    启动自己的 Starter，在运行页选择它

    实现模板后，使用 --agent-entry 加载自己的入口，--server 指向已打开的本机运行页地址。

    python3 starter.py --server <本机运行页的根地址> --agent-entry adapter_template:run --name "My Legal Agent"
