第一次运行：下载、配置模型、开始任务
  1. 下载自动配置启动包

    包含 Mac 与 Windows 启动脚本。解压后，Mac 运行 Start-Mac.command，Windows 运行 Start-Windows.cmd；系统可能要求确认。

  2. 按提示填写自己的模型配置

    填写兼容接口地址、模型名和 API Key。启动器联网下载 Python、浏览器和依赖；密钥只用于当前本机进程，不保存到文件。

  3. 浏览器自动打开后，点击“开始运行”

    保持启动窗口打开。本页查看实时日志与交付结果；运行模型可能产生费用。新运行的 Word 页面预览需要另配文档渲染器，Word 文件仍可下载。

自动配置脚本为预览版，尚未完成全新 Mac / Windows 实机安装验证。需要自定义 Agent 的开发者可下载完整源码，参照 starter 中的适配指南。

若希望访客连启动包和模型密钥也不需要，只在网页点击就能运行，需要我们另行部署云端执行服务；目前这个公开站仍是静态托管。

本机运行与静态回放有什么区别？

本机运行：本页连接本机任务后端，独立 starter 领取任务并回传事件。静态回放：本机完成后导出 .legalgym.json，在此导入；无需运行后端或上传云端，也可以播放过程、翻阅全部 Word 页面和下载合同。

浏览器负责展示和翻页；模型执行和 Word 排版由本机程序完成。首页的固定示例与个人运行记录独立。
