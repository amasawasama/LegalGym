# Legal Gym 本地网页原型

整理日期：2026-11-21

## 打开

直接双击 `index.html`，无需安装依赖、无需服务器、无需联网。Mac 也可双击 `打开网页-Mac.command`。页面不连接真实模型、不发送审核意见、不发布到网络。

## 页面

- 首页：项目定位、六题概况、完整工作流与合作入口。
- 任务与环境：真实六题元数据、搜索筛选、材料清单及下载元数据。
- 体验工作台：模拟交办与三个教学文本，可查看、下载，交付草稿可本机保存及导出。
- 运行回放：四步预设教学回放，支持播放、暂停、前后切换和导出；非真实 Agent 轨迹。
- 评测接入：生成评测配置草案；执行与排行榜是用途说明占位。
- 参与贡献：贡献方式、事项草稿填写、保存与下载。
- 专家审核：模拟审查点、可折叠参考及本机意见草稿；未连接原审核数据库。
- 建设进度：已有资产、原型实现和待建设功能的边界。

## 真实内容与模拟内容

`assets/data.js` 的六题标题、审查点数量、材料文件名及附加条件来自原题库 `律师审核网站/题库/tasks.json` 和对应目录，生成时点为 2026-11-21。95 个参考点不代表已经通过专家正式审定。

原型未复制真实合同正文、隐藏参考答案、账号数据库、密钥或服务器设置。工作台和审核示例是重新编写的教学文本，不是 C02 的完整输入或权威参考。

根目录的 `网站框架大纲.md` 是前期设计文档副本，内部资料的绝对路径已移除。公开发布前仍需核对材料清单元数据的公开范围。

## 数据保存

贡献、复核与交付草稿使用当前浏览器的 localStorage；不会上传。文件模式下部分浏览器可能限制本地存储，请用下载功能保留草稿。清除浏览器站点数据会清空草稿。

## 文件

- `index.html`：页面入口。
- `assets/style.css`：响应式视觉样式。
- `assets/app.js`：导航、筛选、回放与草稿交互。
- `assets/data.js`：已有题库元数据。
- `网站框架大纲.md`：设计依据。

## 验证范围

进行了 JavaScriptCore 脚本执行、页面路由与主要交互检查，以及静态资源检查。当前环境没有可用浏览器自动化工具，未完成真实浏览器截图及视觉验收。

## 仓库范围

仅包含本地展示原型、静态资源、任务元数据、设计大纲和启动说明。不包含原合同、专家参考答案、审核数据库或凭证。建议先以私有仓库保存。
